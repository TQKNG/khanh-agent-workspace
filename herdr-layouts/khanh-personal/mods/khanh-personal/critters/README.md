# Critter art

The sidebar draws small critter pictures from `art/` (files named `sprite-<critter>-<status>.svg`).
This is the retro theme from the herdr-critters mod, bundled here at the repository owner's request.
The upstream repository does not identify a license, so the repository's MIT license does not cover these files.
Replace the files in `art/` to change the pictures, keeping the same file names.

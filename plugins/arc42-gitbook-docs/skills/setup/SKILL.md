# Set up arc42 GitBook Docs

Read ../../references/intake-and-evidence.md before taking action.
Always ask and receive an answer before construction, including when invoked directly for setup.
Inspect connections and existing sites without mutation while waiting.
Accept a GitHub repository, supplied plan, or idea; GitHub is required only for repository input.
GitBook read/write access is required for final delivery.
Resolve all required intake, record provenance and confirm the exact source and destination with the user.
Do not default a branch, product architecture, delivery mode or missing detail.
Route to generate-arc42-docs for complete content generation and create-gitbook-site only after readiness passes for a new destination.
Continue through GitBook delivery instead of stopping at an offer to generate.
